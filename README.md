# やなぎさわ眼科 デモサイト

眼科クリニックのデモサイトです。医院名・住所・医師・連絡先はすべて架空です。

- 構成の参考: 地域の眼科クリニックサイト（診療時間表・診療案内・初診案内・アクセス・予約導線）
- コラムの参考: SmartHR Mag.（カード型の記事一覧、カテゴリ、読みやすい記事ページ）
- デザインの基準: Apple Human Interface Guidelines

## ページ

| パス | 内容 |
| --- | --- |
| `index.html` | トップ（本日の診療状況、お知らせ、診療時間、診療案内、医師紹介、初診、FAQ、アクセス、コラム、予約） |
| `columns/index.html` | 目のコラム一覧（カテゴリ絞り込み付き） |
| `columns/dry-eye.html` | コラム記事の例 |

## HIG に沿った主なポイント

- **タイポグラフィ**: システムフォント（SF Pro / ヒラギノ）と HIG のテキストスタイル階層（Large Title〜Caption）
- **カラー**: システムカラーとセマンティックカラー。ライト/ダークモードを自動で切り替え
- **レイアウト**: 8pt グリッド、タップ領域は最小 44pt
- **Materials**: 半透明ブラーのナビゲーションバー、モバイルのタブバー
- **コンポーネント**: グループ化リスト、セグメンテッドコントロール、シート（モバイルメニュー）、Filled / Tinted / Plain ボタン
- **アクセシビリティ**: スキップリンク、フォーカスリング、`aria` 属性、視差効果を減らす設定・コントラストを上げる設定に対応
- **一目でわかる情報**: 現在時刻から「診療中／時間外」と次の受付時間を表示し、診療時間表の今日の列を強調

## 見かた

ビルド不要です。`index.html` をブラウザで開くか、次のコマンドで確認できます。

```bash
python3 -m http.server 8000
```
