# 牛込柳町弁天眼科クリニック リニューアル提案デモ

ウェブサイトリニューアルの提案用デモです（非公式）。外部に公開せず、ローカルで確認してください。
検索エンジンに載らないよう `noindex` を指定しています。

- 掲載内容: 現行サイト（benten-eye.com）のスマホ表示をもとに作成
- 配色: 現行サイトのくすみローズ・ワイン・トープ
- デザインの基準: Apple Human Interface Guidelines

## ローカルで見る

```bash
git clone -b claude/cool-newton-kgvy7q https://github.com/nagihaya/Ynagisawa-Ganka.git
```

```bash
cd Ynagisawa-Ganka && python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます（`index.html` をダブルクリックで開いても表示できます）。

## 差し替えが必要な箇所

- 院内写真（トップのスライドショー）は編集画面の「写真」タブで差し替え。グループクリニックの写真は今は仮の図
- お知らせ各項目の本文
- 「診療内容はこちら」、グループクリニック・提携医療機関のリンク先
- WEB予約ボタンのリンク先
- 「初診の方へ」の流れ・持ちもの・散瞳検査の注意は一般的な内容のため、医院に確認して確定
- 「デモ用：日時を変えて表示を確認」は本番では削除
- スクリーンショットから読み取った項目の確認: 院長名（「三宮」以降）、グループクリニック「小暮眼科」、提携医療機関の正式名称

## HIG に沿った主なポイント

- システムフォントと HIG のテキストスタイル階層
- ライト/ダークモード自動切替、8pt グリッド、タップ領域 44pt 以上
- 半透明ブラーのナビゲーションバー、スマホ下部のタブバー（電話・WEB予約・TOP）
- 下から出るシートのメニュー、グループ化リスト、開閉式のお知らせ
- 現在時刻から「受付中／時間外」と次の受付時間を表示し、受付時間表の今日の列を強調
- スキップリンク、フォーカスリング、視差効果を減らす設定・コントラストを上げる設定に対応
- なめらかスクロールに Lenis 1.3.26（MIT, `assets/vendor/`）を同梱。「視差効果を減らす」設定の端末では通常のスクロールになります
- 文字のコントラスト確保のため、帯（診療内容・グループ）とフッターの色は現行サイトより少し濃くしています

## 編集画面（admin.html）

臨時休診・お知らせ・受付時間・スライドショーの写真を、フォームで編集できます。右側（スマホでは「プレビュー」）で、サイトへの反映をその場で確認できます。

- 編集する内容は `assets/data.js` にまとまっています
- 「保存」：このブラウザ内に記録（同じブラウザで開いたサイトにも反映）
- 「書き出し」：新しい `data.js` をダウンロード。サーバーの `assets/data.js` と置き換えると公開サイトに反映
- 「元に戻す」：保存した変更を消して `data.js` の内容に戻す
- 写真は選ぶと自動で縮小（最大1600px・JPEG）され、`data.js` に埋め込まれます。本番では画像を別ファイルで置く形にすると軽くなります
- 提案用デモのためログイン機能はありません。本番ではログイン付きの管理画面（CMS）や認証の仕組みが必要です
